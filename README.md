# React Context Hook

React exercise demonstrating shared user context through header and profile components.

## Project structure

- `src/context/UserContext.jsx`
- `src/components/Header.jsx`
- `src/components/Profile.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/context-Hook.git
cd context-Hook
```

Install Node.js and npm. Run `npm install` followed by `npm run dev`. Open the URL shown in the terminal.
